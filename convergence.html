How This Was Built

Inclusion Criteria

Teachers were selected if their prophetic framework produces specific, dateable markers — either from mathematical calculation, astronomical cycles, calendar patterns, or verified prophetic track records.

Methodology Types

Calendar (Biltz, Cahn, Nettles): Shemitah, Jubilee, and Daniel 70-week cycles. Astronomy (Nettles, Biltz): Blood moon tetrads, eclipse patterns. Prophetic (Clement, Biggs): Recorded visions with verified fulfillments. Scriptural (Prince): Fig tree generation framework from Matthew 24.

What This Is Not

This is not date-setting. It is a documentation of where multiple independent witnesses converge on the same general seasons, presented for your examination. The day and hour remain unknown (Matthew 24:36).
